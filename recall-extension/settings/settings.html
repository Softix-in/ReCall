Recall Settings

Stored locally in ~/.recall/settings.json

Server connection

Use the default for local Recall, or point to your hosted server (HTTPS recommended).

Backend connection

Use local backend by default. Point to your hosted server when the daemon is not running on this PC.

Keyboard shortcuts

Configured in chrome://extensions/shortcuts

  • Quick save: Ctrl+Shift+S (Cmd+Shift+S on Mac)
  • Open search: Ctrl+Shift+F (Cmd+Shift+F on Mac)
